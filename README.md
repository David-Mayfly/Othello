# Othello Vault — clickable prototype

Single-file HTML prototype of Othello Vault for Medcentric. Open `index.html` in a browser — no build step or dependencies.

**Sign in:** choose a view from the *View as* dropdown and use the demo password `Jupiter`. (The password is checked client-side — it keeps casual visitors out, it is not real security.)

## Views (switch any time from the *Viewing as* chip or the user menu)
- **Client Administrator** — advice areas (Credit, Tax, SMSF, Insurance, Legal), product providers, product list, requirement rules, application form templates, field mapping (link each PDF form field to the fact find, the customer record, a Vault document, the strategy pack, a calculation or manual entry, then publish), document library, Vault settings
- **Advisor** — dashboard (advice areas, pipeline, upcoming sessions), customer CRM, sessions, and New customer. The fact find happens outside Othello at the discovery meeting and is saved to the customer's Google Drive folder; the advisor enters first name, surname and date of birth, Othello finds the folder, checks for an existing customer, reads the fact find and matches each answer to the customer record for review, then creates the record in Customers (simulated)
- **Team Member** (specialist team) — customers, customer profile and customer view, checklists, issues, pre-filled application forms, strategy, Vault

Terminology follows the Othello Vault project scope: the **Client** is the advisory firm (Medcentric) and the **Customer** is the household being advised. Lifecycle: Discovery → Strategy → Acceptance → Document collection → Ready → Lodged.

All customer data is fictional. Wealth products are mapped to the MC Wealth Services APL (13/04/2026).
